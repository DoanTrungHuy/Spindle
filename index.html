Abstract — Spindle is a high-performance, multithreaded Key-Value store engineered in Modern C++20. Designed for developers who demand absolute control over concurrency and memory.

Explore Architecture

System Architecture & Design

Write-Ahead Logging (WAL)

Data durability is guaranteed via an asynchronous Write-Ahead Log, fueled by a lock-free MPSC Ring Buffer to eliminate I/O blocking.

Sharded Hash Map Architecture

The core database is divided into multiple independent shards (partitions). This significantly reduces global lock contention, allowing multiple threads to read and write simultaneously for massive throughput.

Userspace Spinlocks

By avoiding expensive OS-level mutex context switches, Spindle achieves ultra-fast lock-free multi-core synchronization. Perfect for high-contention environments.

Slab Allocator

Custom memory management that eliminates heap fragmentation and maximizes CPU cache locality.

Reactor Pattern

Epoll-based architecture to multiplex thousands of concurrent TCP connections seamlessly.

Active & Lazy Expiry

TTL and key expiration is handled gracefully via background cleaner threads and on-demand lazy eviction, ensuring memory is freed without blocking readers.

Commands Reference

Spindle uses a simple, human-readable text protocol over TCP. Every command must be terminated with a newline (\n).

Multi-Language SDKs

Spindle speaks plain TCP. You can use our provided clients or easily write your own in any language.

import clients.java.SpindleClient;

public class Main {
    public static void main(String[] args) {
        SpindleClient client = new SpindleClient("127.0.0.1", 8888);
        try {
            client.connect();
            
            // Set key with expiration (3600 seconds)
            client.setEx("session:1", "active", 3600);
            System.out.println(client.get("session:1"));
            
            client.delete("session:1");
        } catch (Exception e) {
            e.printStackTrace();
        } finally {
            client.close();
        }
    }
}
const SpindleClient = require('./clients/javascript/spindle');

async function main() {
    const client = new SpindleClient('127.0.0.1', 8888);
    
    try {
        await client.connect();
        
        // Set key with expiration
        await client.set("session:1", "active", { ex: 3600 });
        console.log(await client.get("session:1"));
        
        await client.delete("session:1");
    } catch (err) {
        console.error(err);
    } finally {
        client.close();
    }
}

Installation & Setup

Get Spindle up and running in seconds. Build from source or include it directly in your CMake projects.

# 1. Clone the repository
$ git clone https://github.com/DoanTrungHuy/Spindle.git
$ cd Spindle

# 2. Build the project using CMake
$ mkdir build && cd build
$ cmake ..
$ make -j4

# 3. Start the server!
$ ./spindle_app --port 8888 --threads 4

# Add the following to your CMakeLists.txt:

include(FetchContent)

FetchContent_Declare(
  Spindle
  GIT_REPOSITORY https://github.com/DoanTrungHuy/Spindle.git
  GIT_TAG        master
)
FetchContent_MakeAvailable(Spindle)

# Link it to your executable
add_executable(my_app main.cpp)
target_link_libraries(my_app PRIVATE spindle)
